## MAKI v95: class ambiguity + 近似牌矛盾 + 学習保存分離
- YOLO出力からTop1だけでなく **第2候補・第2score・Top1との差(class margin)** を保持。
- class marginが極端に小さい、またはscoreも低くmarginが小さい牌は、保守的補助認識が同じ牌を確認できない限り自動確定しない。
- 補助認識のTop候補がYOLOの第2候補と一致し、marginが小さい場合も要確認へ回す。
- crop特徴が非常に近い同系牌2枚に別ラベルが付いた場合、confidence/marginが弱い側を要確認へ回す。今回の **發・發なのに南・發** を一般化した安全策。
- 認識詳細を開くと、各牌について **Top1 score / 第2候補score / class margin** を確認できる診断表示を追加。
- 学習保存のprimary readback検証は、実際に学習対象になった非broken牌のラベルだけを対象に修正。
